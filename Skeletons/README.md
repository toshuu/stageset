# Skeletons

Store code blueprints in this folder.

Mirror the relative directory path of each target source file. Add the required `@stageset` metadata in the file's normal comment syntax.

A skeleton is ready when it has enough detail for a coding agent to implement it without repeating the main design work.

Do not place working application code here.

For a target format that does not support comments, use a Markdown sidecar file with the `.skeleton.md` suffix. Keep its `@stageset target` metadata exact.
