# Claude Code instructions

This workspace uses StageSet. Before you inspect or change project code, read:

1. `STAGESET.md`
2. `.stageset/config.yml`
3. `coder-rules.md`
4. `.stageset/sessions-tracker.md`

Use `python scripts/stageset-status.py` to find ready skeletons. Read the related idea, skeleton, and current source files before you implement anything.

Treat each ready skeleton as the implementation contract. Do not guess when a plan is unclear. Preserve existing functionality unless the approved plan requires a change.

Use ASD-STE100-style English in project documents, comments, and session summaries. Update the global session tracker after each focused coding session. Record a `PUSH` event only after a remote push succeeds.
